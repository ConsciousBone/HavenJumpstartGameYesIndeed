# haven jumpstart game yes indeed
A simple platformer made in Godot. Need I say more?

# Stuff I used to make this
- Some scripts I made in [untitled adventure game](https://github.com/headblockhead/daydream-manchester), the project I and 2 other people worked on for Daydream Manchester
- [Generic Grass/Dirt Tileset](https://sourix5042.itch.io/generic-grassdirt-tileset)
- [Pixel Dimensional Portal 32x32](https://pixelnauta.itch.io/pixel-dimensional-portal-32x32), cropped to only include 1 state
- [Free Sky Backgrounds](https://free-game-assets.itch.io/free-sky-with-clouds-background-pixel-art-set), edited to squish all 4 cloud assets into 1 image
- [Pixel Protagonist](https://penzilla.itch.io/protagonist-character), cropped to only include 1 state
- [skristi's Coins asset pack](https://skristi.itch.io/skristis-coins-asset-pack)
