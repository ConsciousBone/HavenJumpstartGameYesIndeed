A simple platformer I made in Godot. Need I say more?  
I need to say more? OK then, it's got:

- 5 levels
- 5 portals, 1 on every level
- A start screen
- An end screen

# Gameplay
This game is very simple! You use these keys:
- A/left arrow -> Move left
- D/right arrow -> Move right
- W/space/up arrow -> Jump
- Backspace -> Move back to that level's spawn point (useful if you get stuck!)
- ESC -> Go back to title screen
  
to move through each level, collecting as many coins as possible on your way. Touching the portal brings you to the next level.

# How to play
Visit [this itch.io page](https://consciousbone.itch.io/havenjumpstartgameyesindeed) and run the game in your browser!  
Alternatively, you can download the repo, open the project in Godot, and run it through that instead.
